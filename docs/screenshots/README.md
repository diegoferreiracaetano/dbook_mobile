# Demonstração do app de clientes

Capturas do app (web, 400 × 860) contra a API real (`dbook`, com os seeds `seed-flights`, `seed-hotels` e `seed-airline-logos`), em 2026-10-10.

| # | Tela | O que mostra |
|---|---|---|
| 01 | Home, aba Voos | busca única voo/hotel, destinos em destaque com nota e preço real |
| 02 | Busca preenchida | origem e destino escolhidos pelo seletor de aeroporto |
| 03 | Resultados de voo | logo de cada companhia, horários, classe e preço |
| 04 | Detalhe do voo | logo, aeronave, assentos livres em tempo real, histórico de preço, alerta |
| 05 | Home, aba Hotéis | o mesmo cartão de busca do voo (destino, entrada, saída, hóspedes) |
| 06 | Vitrine de hotéis e pacotes | carrossel com foto do hotel e pacotes voo + hotel com foto da cidade |
| 07 | Perfil | foto, "membro desde", resumo, preferências, conta, dispositivos |
| 08 | Preferências de viagem | aeroporto de origem, classe, assento, moeda e idioma (guardados no servidor) |
| 09 | Home com a origem das preferências | origem já preenchida pela conta |
| 10, 11 | Tema escuro | Home e Perfil |
| 12 | Pacotes no tema escuro | botão "Ver voos" branco com o azul da marca, legível nos dois temas |
